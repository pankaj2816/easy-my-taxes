## 🚀 How to Run Locally

```bash
# Using Python
python -m http.server 8000

# Or using Node.js / npx
npx serve .
```
Navigate to `http://localhost:8000` in your web browser.

---

## 🌐 Deploy to GitHub Pages for Client Viewing

1. Create a repository on GitHub (e.g. `easy-my-taxes-website`).
2. Run:
```bash
git remote add origin https://github.com/YOUR_USERNAME/easy-my-taxes-website.git
git branch -M main
git push -u origin main
```
3. In your GitHub repository: Go to **Settings** > **Pages** > Select branch `main` and `/ (root)` > Click **Save**.
4. Your website will be live at `https://YOUR_USERNAME.github.io/easy-my-taxes-website/`.
